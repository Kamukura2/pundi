# CVFinance v7.7.1

- History is a tracking ledger only. Income and expense entries never change account balances, current net worth, projected cash, or Prospect.
- Expense History entries still fill the matching Monthly Budget meter for the active month.
- History Budget Pace renders every category from Expenses > Budget instead of three hard-coded groups.
- Transaction channels are quick tags with reusable presets and a custom-tag action.
- Yearly expense due cards use the same dark-blue, white-text treatment as Events.
- USD/IDR refresh tries Google Finance and Google Search. When Google blocks server access, the app uses the user-verified Rp17,810 fallback instead of retaining the incorrect Rp17,885 rate. A manual Google rate editor is available next to refresh.
